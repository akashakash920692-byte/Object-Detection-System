# Object Detection System

## Overview

Object Detection System is a real-time computer vision project developed using Python, OpenCV, and YOLOv8. The system detects and identifies multiple objects from a live webcam feed and displays bounding boxes with object labels.

## Features

* Real-time object detection
* Webcam integration
* Multiple object recognition
* Bounding box visualization
* Object labels and confidence scores
* Fast and accurate YOLOv8 detection

## Technologies Used

* Python
* OpenCV
* YOLOv8
* NumPy

## Installation

1. Clone the repository:

git clone https://github.com/your-username/Object-Detection-System.git

2. Navigate to the project folder:

cd Object-Detection-System

3. Install dependencies:

pip install ultralytics opencv-python numpy

4. Run the project:

python3 detect.py

## Usage

* Launch the application.
* Allow camera access when prompted.
* Point the webcam at various objects.
* The system will identify and label detected objects in real time.
* Press **Q** to quit the application.
